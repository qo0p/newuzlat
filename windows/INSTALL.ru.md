# Установка узбекской латинской раскладки

Эта раскладка добавляет в Windows клавиатуру **Uzbek Latin**, чтобы можно было
печатать буквы **ş ç ğ ö** (и **Ş Ç Ğ Ö**) на обычной клавиатуре. Это просто
раскладка клавиатуры — никакие программы в фоне не работают.

## Что вы получили

Папку (или zip-архив) с файлом **`setup.exe`** и одним или несколькими файлами
**`.msi`**. Держите их вместе — `setup.exe` нужны файлы `.msi` рядом.

## Установка

1. Если вам прислали zip-архив, **сначала распакуйте его** (правой кнопкой →
   «Извлечь все»). Не запускайте `setup.exe` прямо из архива.
2. **Правой кнопкой по `setup.exe` → «Запуск от имени администратора».**
3. Если появится окно **«Система Windows защитила ваш компьютер»**, нажмите
   **«Подробнее» → «Выполнить в любом случае»**. (Это окно появляется потому,
   что установщик не подписан; он безопасен.)
4. Дождитесь завершения. Раскладка устанавливается для **всех пользователей**
   компьютера.
5. **Перезагрузите компьютер.** Это обязательно — раскладка полностью не
   активируется до перезагрузки, а без неё панель задач может мигать.

## Включение (после перезагрузки)

Сначала посмотрите на панель задач (справа внизу, рядом с часами): если
индикатор **UZB** уже есть, установщик добавил раскладку за вас — переходите к
разделу «Как печатать». Если нет, добавьте её:

1. Откройте **Параметры → Время и язык → Язык и регион**.
2. Если **Узбекский (латиница)** отсутствует в списке языков: **Добавить язык**,
   найдите **Узбекский (латиница)**, затем **Далее → Установить**. Снимите
   дополнительные опции (язык интерфейса, распознавание речи, рукописный ввод) —
   нужна только клавиатура — и **не** делайте его языком интерфейса Windows.
3. Нажмите **⋯** рядом с **Узбекский → Параметры языка**. В разделе
   **«Клавиатуры»** нажмите **«Добавить клавиатуру»** и выберите **«Uzbek
   Latin»**. (Это ключевой шаг: при простом добавлении языка ставится
   *стандартная* узбекская клавиатура, а не эта.) Если добавилась и стандартная
   узбекская клавиатура и она вам не нужна — нажмите на неё → **«Удалить»**.
4. Теперь на панели задач появится индикатор **UZB**. Переключайтесь между
   раскладками сочетанием **Win + Пробел** (удерживая Win, нажмите Пробел) или
   щёлкнув по индикатору **UZB / ENG**.

## Как печатать буквы

Переключитесь на **UZB**, затем удерживайте **правый Alt** (AltGr) и нажмите
букву:

| Клавиши                              | Результат |
|--------------------------------------|-----------|
| Правый Alt + S                       | ş         |
| Правый Alt + Shift + S               | Ş         |
| Правый Alt + C / G / O               | ç / ğ / ö |
| Правый Alt + Shift + C / G / O       | Ç / Ğ / Ö |

Все остальные клавиши печатают как обычно. Для обычного ввода на английском
вернитесь на **ENG** сочетанием Win + Пробел.

## Удаление

1. **Параметры → Время и язык → Язык и регион →** у узбекского языка
   **⋯ → Параметры языка →** в разделе «Клавиатуры» нажмите **«Удалить»** у
   «Uzbek Latin».
2. **Параметры → Приложения → Установленные приложения →** найдите
   **«Uzbek Latin» → Удалить**.
3. **Перезагрузите компьютер.**
