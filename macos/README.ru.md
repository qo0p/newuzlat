# Узбекская латинская раскладка — macOS

Печатайте новые узбекские латинские буквы **ş ç ğ ö** (и **Ş Ç Ğ Ö**) на обычной
клавиатуре US с помощью клавиши **Option (⌥)**. Это раскладка клавиатуры —
никакие программы в фоне не работают.

(В macOS нет отдельной клавиши AltGr, поэтому используется **Option** — это
аналог слоя AltGr из версий для Windows и Linux.)

| Клавиши              | Результат |
|----------------------|-----------|
| ⌥ Option + S         | ş  (⌥⇧S → Ş) |
| ⌥ Option + C         | ç  (⌥⇧C → Ç) |
| ⌥ Option + G         | ğ  (⌥⇧G → Ğ) |
| ⌥ Option + O         | ö  (⌥⇧O → Ö) |

Все остальные клавиши печатают как на обычной раскладке US.

## Исходный файл

`UzbekLatin.keylayout` — раскладка, текстовый XML-файл (формат, который загружает
macOS). Он написан вручную и **не тестировался на macOS**, поэтому проверьте его
после установки и сообщите о любых ошибках.

## Установка

1. Скопируйте **`UzbekLatin.keylayout`** в папку:
   - `~/Library/Keyboard Layouts/` — **рекомендуется** (только для текущего
     пользователя; это надёжное расположение, раскладка появляется после
     обычного выхода из системы и повторного входа), **или**
   - `/Library/Keyboard Layouts/` — для всех пользователей (потребуется пароль
     и, как правило, полная **перезагрузка**, прежде чем раскладка появится).

   В Finder используйте **Переход → Переход к папке…** (⇧⌘G) и вставьте путь.
   Создайте папку `Keyboard Layouts`, если её нет.
2. **Выйдите из системы и войдите снова** (или перезагрузитесь). macOS ищет
   новые раскладки только при входе.
3. Откройте **Системные настройки → Клавиатура → Ввод текста → Источники ввода
   → Изменить…**
4. Нажмите **+**, выберите **Другие** (или прокрутите вниз) → **Uzbek Latin** →
   **Добавить**.
5. Переключайтесь на неё из меню ввода в строке меню или сочетанием **⌃ Space**
   (Control+Пробел).

## Как печатать

Выберите **Uzbek Latin** в меню ввода, затем удерживайте **Option (⌥)** и
нажмите S / C / G / O. Добавьте **Shift** для заглавных. Всё остальное печатается
как обычно.

## Примечания

- **Gatekeeper:** `.keylayout` — это просто данные, а не программа, поэтому нет
  предупреждения о «неустановленном разработчике» и ничего не нужно нотаризовать.
- **Слой Option предназначен только для этих четырёх букв.** Стандартные символы
  Option в macOS (å, ∂, ç через Option-c, «мёртвые» клавиши для диакритики и т. д.)
  **не** вводятся, пока активна эта раскладка. Для них переключитесь обратно на
  обычный источник ввода **U.S.**

## Удаление

1. **Системные настройки → Клавиатура → Ввод текста → Источники ввода →
   Изменить… →** выберите **Uzbek Latin → −** (удалить).
2. Удалите `UzbekLatin.keylayout` из папки `Keyboard Layouts`, которую вы
   использовали.
3. Выйдите из системы и войдите снова.

## Сборка с нуля (необязательно)

Чтобы пересоздать или изменить раскладку в графическом редакторе, используйте
**Ukelele** (бесплатно). Если вы хотите сохранить все стандартные символы Option
в macOS *и* добавить эти четыре буквы, проще всего открыть системную раскладку
**U.S.** в Ukelele, изменить только вывод Option / Option+Shift для клавиш
S, C, G, O и экспортировать.
